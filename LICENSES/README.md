The complete Apache license variants differ only in file formatting/content retained from their sources. Their exact hashes and copy provenance are recorded in [PROVENANCE.json](../PROVENANCE.json).

Eight license paths explicitly cited by the copied sources are also retained under `docs/`. Historical dossier references for the symmetric-algebra port, UW Nagata port and the AINTLIB section-zero port resolve to the applicable Apache text in this directory and to the exact upstream revisions listed in the notices. Private source dossiers are outside this distribution.
